# Рубрика скоринга (рынок РФ)

> Версия v1 — реализуется в задаче T310 (промпт `llm/prompts/score.md`).
> Скор — число 0–100 + обязательное текстовое обоснование + цитаты-доказательства.

## Критерии и веса (v1)

| # | Критерий | Вес | Что оценивает LLM |
|---|---|---|---|
| 1 | Частота и разброс | ×2 | Сколько постов в кластере, из скольких разных источников |
| 2 | Свежесть | ×1.5 | Возраст постов кластера, динамика (растёт/затухает) |
| 3 | Платёжеспособность аудитории | ×1.5 | Кто страдает: бизнес платит охотнее частных лиц; B2B > B2C |
| 4 | Конкуренция | ×1 | Есть ли готовые решения на рынке РФ, насколько насыщен сегмент |
| 5 | Монетизируемость | ×2 | Ясна ли модель денег; `kind=demand` в кластере — сильный плюс (заказ с биржи = доказанный платёжный спрос) |
| 6 | Регуляторные риски | ×1 | Лицензии, сертификация, работа с персональными данными, госуслуги |
| 7 | Сложность MVP | ×1.5 | Насколько дорого/долго собрать первую версию одному разработчику |

## Правила рубрики

1. **kind=demand усиливает монетизируемость**: заказ на бирже — прямое доказательство рынка, а не догадка. Кластер с ≥1 demand-постом получает заметную прибавку по критерию 5.
2. **Обоснование обязательно**: скор без `rationale_md` не проходит валидацию — счётчик брака в `run`.
3. **Sanity-гейт распределения**: если все скоры вылезли в узкий диапазон (например 80–90), рубрика вырождена — флаг в stats прогона, страница «Здоровье системы» подсвечивает.
4. **Цитаты-доказательства**: скор опирается на конкретные цитаты кластера; без цитат скор не принимается.

## Калибровка (post-MVP)

- Петля: твои кнопки «интересно/скрыть» на кластерах → логистическая регрессия поверх признаков
  (частота, источники, kind-микс, свежесть…) → предложение новых весов через кнопку «применить калибровку».
- Смена рубрики = новая версия промпта `score` в `prompt_version` → регрессия на фикстурах →
  перегон кластеров со сравнением скоров (страница «Промпты»).
