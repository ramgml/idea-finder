# Документация пользователя idea-finder

Папка для документации по работе с системой: руководства, сценарии, FAQ.

Планируемые документы (создаются по мере готовности системы):

| Файл | Что описывает | Когда появится |
|---|---|---|
| getting-started.md | Установка (uv sync), первый запуск, поднятие БД | после T294–T297 |
| dashboard.md | Страницы дашборда: Кластеры, Источники, Промпты, Настройки LLM, Здоровье | после F1–F7 |
| run.md | Как запустить полный сбор, читать статусы, трактовать скоры | после G1 |
| sources.md | Как добавлять источники, управлять реестром, ручная капча | после B1–B5 |
| prompts.md | Как редактировать промпты, читать регрессию, откатывать версии | после F4 |
| faq.md | Типовые проблемы: капчи, заблокированные домены, качество скора | по накоплению |

Правило: docs/ — «как пользоваться» (для человека за клавиатурой), context/ — «как устроено» (для агентов и разработчика). Документ в docs/ создаёт PM-поток, который закрыл соответствующую функциональность.
